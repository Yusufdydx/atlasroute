# ATLASROUTE MCP - VERIFICATION & APPROACH DOCUMENTATION

## Current Status - APPROVED APPROACH

### Our Value Proposition (As Approved)

We help people FIND healthcare facilities. We do NOT guarantee or claim:
- Specific hospital capabilities (stroke center, cardiac cath lab, trauma level)
- Verified specialty services
- 24/7 availability
- Current operational status

### Safe Language Used

| When User Asks | We Say |
|----------------|--------|
| "Find stroke hospital" | "Find hospitals - verify capability by calling ahead" |
| "Find cardiac care" | "Find hospitals - verify cardiac services by calling" |
| "Find 24/7 pharmacy" | "Find pharmacies - call to verify hours" |
| "Which hospital handles emergencies" | "Find hospitals with emergency rooms - confirm with facility" |

## What Requires Disclaimer

### Filter Results
When user filters by specialty, we return facilities with matching keywords in name/amenities, but ALWAYS include:
- "Verify capabilities by calling facility directly"
- "Hospital services may change"
- "This is based on available information"

### All Tool Outputs Include
```
verificationNote: "Verify capabilities by calling facility directly. Hospital services may change."
```
